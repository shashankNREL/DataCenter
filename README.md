# DataCenter

Power-generation surrogate models and dynamics for data-center workload studies. See `docs/` for phase and tier documentation.

The scheduler-controlled GPU ramp demonstration is described in
[`docs/scheduler_ramp_demo.md`](docs/scheduler_ramp_demo.md). Run it with
`pixi run scheduler-ramp-demo`.

For a plain-language explanation of the code, results, and limitations, see the
[study report (PDF)](docs/scheduler_ramp_demo_report.pdf) or its
[LaTeX source](docs/scheduler_ramp_demo_report.tex).
